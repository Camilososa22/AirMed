# Evidencias gráficas de AirMed

Esta carpeta contiene las visualizaciones generadas durante
la evaluación de los modelos de predicción de PM2.5.

## Archivos

### prediccion_prueba.png

Gráfica que compara las concentraciones observadas de PM2.5
con las predicciones generadas por el modelo GRU durante
un horizonte de 24 horas.

La visualización permite examinar la capacidad del modelo
para seguir los cambios temporales en la concentración
del contaminante.

Los resultados corresponden al conjunto de prueba utilizado
en el experimento de AirMed.
