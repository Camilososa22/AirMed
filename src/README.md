Archivos fuente y dependencias de AirMed
Este paquete contiene los scripts Python y las dependencias para incorporar a la raíz y a la carpeta `src/` del repositorio AirMed.
Copia el archivo `requirements.txt` a la raíz del repositorio.
Copia el contenido de `src/` a una carpeta `src/` en el repositorio.
No subas datos privados, credenciales ni archivos temporales.
Consulta `src/README.md` para las instrucciones de ejecución.
