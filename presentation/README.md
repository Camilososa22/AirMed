# Presentación de AirMed

Esta carpeta contiene el material de presentación del proyecto
AirMed, desarrollado como parte de un taller académico de
Deep Learning.

## Archivos

- `AirMed.pptx`: presentación editable del proyecto.

## Contenido

La presentación describe la problemática abordada, los datos
históricos de SIATA, el análisis exploratorio, el preprocesamiento,
las arquitecturas LSTM y GRU, el entrenamiento, las métricas
de evaluación y las conclusiones del proyecto.
